
# WattWise

WattWise is a full-stack electricity consumption analysis
application designed initially for Indian households.

## Planned Features

- Monthly electricity bill tracking
- Manual meter reading tracking
- Bill and meter-reading reconciliation
- Consumption analytics and visualizations
- Anomaly detection
- Consumption and bill forecasting
- Evidence-grounded AI explanations

## Technology Stack

- Frontend: React and Vite
- Backend: Node.js and Express
- Database: PostgreSQL
- Analytics: Python, pandas and NumPy
- Python API: FastAPI
- Machine Learning: scikit-learn
- AI explanations: LLM API

## Project Structure

- frontend/ — React application
- backend/ — Express API
- analytics/ — Python analytics service
- database/ — schema, migrations and seed data
- docs/ — project documentation
